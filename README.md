# AI Research Pipeline

Pipeline for multi-agent research.

Stages:

1. Исследование — сбор фактов и материалов
2. Анализ — формирование выводов
3. Гипотезы — проверка проблем и решений
4. Синтез — подготовка результата

Каждый этап читает предыдущий результат и создаёт артефакт для следующего этапа.
